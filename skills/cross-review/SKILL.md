# クロスレビュー（自作をまとめて採点する）

書き上げた作品をまとめて読み、**編集者の評価**と、**10代〜70代の男女14人の読者像**による点数（10点満点）と一言を付ける。
目的は、一作ずつ読んでいると見えない**作品をまたいだ癖**と、**どの読者に届いて、どの読者に届いていないか**を見ること。

1話ごとの直しは別の skill（editor-review）でやる。こちらは作品単位の通信簿。

## 決めごと（最初に書き手に伝える）

- **甘くしない。** 一緒に書いた AI が採点すると甘くなりやすい。全作品で弱い点を必ず三つ書く
- **読者像14人は架空。** 実在の読者の声ではない。評価ファイルの冒頭にそう書く
- **読んでいない部分を想像で評価しない。** 全文を読めなかった作品は、何を読んだか（冒頭・途中・最終話・プロットなど）を書き、粗さがあると断る
- **結末に触れるかどうかを書き手に聞く。** 評価を人に見せるつもりなら、講評でネタを割らない
- 評価する AI が本文づくりに関わった作品は、そう書く

## 手順

### 1. 対象を決める

- 書き手に、どの作品を入れるか聞く。完成済み・連載中・応募中・公開前を分けて確かめる
  - **コンテストに応募中の作品**は、結果が出るまで外すか、評価を公開しない（規約の「未発表」に触れるおそれ）
- 作品ごとに、原稿の場所・区分（長編・中編・短編・掌編）・字数・公開先を控える
- 設定資料・プロット・過去の編集者評価があれば、参考に読む

### 2. 文の型を数える

```bash
python3 <このスキルのフォルダ>/scripts/style_stats.py 作品Aの原稿フォルダ/ 作品Bの原稿フォルダ/ 作品C.md
```

一文あたりの読点と、「〜た。」で終わる文の割合が作品ごとに出る。全体の評の「文の型」に使う。
話ごとの数字が欲しければ `--each`。数字は目安で、合否ではない。

### 3. 作品ごとに評価する

各作品について：

1. **編集者の点**（10点満点）と、**良い点三つ・弱い点三つ**。構成・人物・テンポ・引き・整合性・文の質を見る。場面や台詞を引いて具体的に
2. **直すなら**：いちばん効く直しを一つだけ
3. **読者14人の点とひとこと**：`references/readers.md` の人物になりきって付ける。心得もそこに書いてある
4. 読者14人の**合計と平均**、**殿堂**（平均 8.0 以上プラチナ／7.0 以上ゴールド／6.0 以上シルバー）

**点数の目安**：10＝この人に迷わず勧める／7＝その層なら楽しめる／5＝合う人には合う／3以下＝その層には届かない

作品が多いときは、一作ずつ読んで書き、最後に全体をまとめる。長編を全部読めないときは、冒頭・途中・最終話を読む。

### 4. 全体を通してまとめる

作品をまたいで見えることを、数字と作品名を添えて書く。ここがいちばん書き手の役に立つ。

- **どの長さ・形が強いか**：区分ごとの読者平均と、上位の作品に共通すること
- **文の型**：手順2の数字。いちばん速くあるべき場面まで同じ速さになっていないか
- **作品をまたいで出る癖**：同じたとえ・同じ人物の型（疲れた中年・頭をぶつける大男など）・同じ締め方（沈黙で閉じるなど）。一作ずつ読むと気づかないが、同じ作者を続けて読む人は気づく
- **届く層の偏り**：読者ごとに全作品の平均を出し、いちばん届いている層と届いていない層、その理由の見立て
- **題**：中身を指しているか。投稿先で不利になっていないか

### 5. ファイルに書く

- ひな形は `references/template.md`。一覧（読者平均の高い順）→ 全体の評 → 作品ごとの順に並べる
- 置き場所は書き手に聞く。決まりが無ければ、作品をまとめたフォルダの直下に `cross_review_<YYYY-MM-DD>.md`
- 書き手が記事にしたいと言ったら、表の使えない投稿先（note など）では一覧を箇条書きにし、書き手の感想の箇所は `【著者確認：…】` と印を付けて、推測で埋めない

## 守ること

- 点は**読者ごとに散らす**。14人がそろって同じ点なら、なりきれていない
- 本文に無いものを褒めない・けなさない
- 作品の主張の良し悪し（政治・社会の立場）を点にしない。見るのは書き方と届き方
- 煽り・釣り・PV狙いの直し（題を過激にする、引きを過剰にする）は提案しない
- 字数は目安。長いこと・短いことそのものを弱点にせず、中身が薄くなっているかで見る

## ファイル

- `references/readers.md`：読者像14人と、点を付けるときの心得
- `references/template.md`：評価ファイルのひな形
- `scripts/style_stats.py`：作品ごとの読点・「〜た。」止めを数えるツール（標準ライブラリだけ・Python 3.9 以上）
