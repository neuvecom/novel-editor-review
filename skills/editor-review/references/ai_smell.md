# AI臭さの点検（書くとき・編集者評価のとき）

生成AIと一緒に書いた日本語の小説には、AI の地の文に出やすい癖が残りやすい。
ここに挙げるのは、ある書き手が自作16作品（初期作から最近作まで）を点検して見つけた癖と、その直し方。

**大事なこと：癖は時期によって種類が変わる。** 初期の「やりすぎ」の癖が消えると、「静かすぎて全部同じ」の癖が出てくる。どちらも見る。

## いつ使うか

| 場面 | やること |
|---|---|
| 本文を書くとき | 下の「書くときのルール」を守る |
| 書き終えたら（編集者評価の前） | `scripts/ai_check.py` を走らせる |
| 編集者評価 | 評価ファイルに「AI臭さ」の節を必ず作る（書き方は下） |
| 連載・連作で新しい話を足したとき | **全話で**走らせ直す（章末の重なりは話をまたがないと見えない） |

## 癖の一覧

例文はどれも説明のために作ったもの。

### A. やりすぎの癖（書き始めのころに多い）

| 癖 | 例 | 直し方 |
|---|---|---|
| 章末のまとめ・教訓 | 「それが、彼という男の選んだ生き方だった。」 | **消す。**その直前の会話や動作で止める |
| 「Xではない。Yだ。」の言い切り | 「英雄の凱旋ではない。ただの郵便屋の帰宅だ。」 | 1作に1回まで。章末には置かない |
| 気持ちの説明 | 「二人の言葉の奥で、もう一つ別の気持ちが静かに交換された。」 | 会話で伝わっていれば消す。伝わっていなければ会話を直す |
| 「――」の決め行・読点の打ちすぎ | 「窓の外では、また、春が、巡っていた。」 | 「――」で名言を切り出さない。山場ほど読点を**減らす** |
| 決まり文句の反応 | 「部屋の空気がぴしりと凍った。彼女が息を呑む。」 | その人物にしかしない反応を書く |

### B. 静かすぎる癖（慣れてきてから多い）

一文ずつは上手いので、**慣れると「いい文章」に見える**。ここが見落としやすい。

| 癖 | 例 | 直し方 |
|---|---|---|
| 「〜た。」の連続 | 「た。」で終わる文が3つ続く箇所が全体の半分を超える | 緊迫した場面では「〜る。」や体言止めを混ぜ、日常の場面では一文を長くする。**場面ごとに速さを変える** |
| 沈黙で閉じる | 「彼は、何も言わなかった。」が1作で30回以上 | 沈黙の代わりに、具体的な動作か短い台詞を置く。沈黙そのものが主題の作品は別 |
| 先の出来事の予告で章を閉じる | 「〜のは、それから二十一年あとのことである。」 | 1作で1〜2回まで |
| 同じ小道具で章を閉じる | 「ポケットの中の小さな丸いバッジ」が3話の締めに出る | 1作で1回。**意図したリフレイン**は可。その場合は評価ファイルに「意図したもの」と書く |
| 二段ぼかし | 「〜だったのかもしれない。あるいは、〜だったのかもしれない。」 | どちらかに決める。決められないなら両方消す |
| 数え上げの台詞 | 「一つ。沢の水で発電できる」「二つ。」「三つ。」 | 説明を台詞で箇条書きにしない。一番大事な一つだけ言わせる |
| 「少しだけ」の多用 | 他の作品の2〜3倍出ている | 「少し」を取っても意味が変わらないなら取る |
| 読者に計算させる | 「Dで一年、Cで一年。Cに上がって一年たったころ」「四年前の秋、と思ってから、七年前だと数え直した」 | 足し算・引き算・割り算をしないと読めない数字は、答えだけ書くか、外す。証拠として要る数字だけ残す |

## 書くときのルール

1. **章の最後の3行は、まとめ・教訓・予告・沈黙のどれでもない形で閉じる。** 具体的な動作・台詞・物で止めるのはよいが、前の話と同じ物で止めない
2. **語り口の型を先に決める。** 点検で癖が少なかった作品は、どれも語りの型（古典の文語調・落語の高座・ナンセンス・朗読劇）が先にあった。型が弱いと AI の「地の文」が出る
3. **場面の緊張に合わせて文の長さを変える。** 全部が同じ歩幅にならないように
4. 壁打ちに使った AI の言い回しを、そのまま本文に持ち込まない

## `scripts/ai_check.py` の読み方

```bash
python3 scripts/ai_check.py <原稿フォルダ>        # 全話（まえがき・あとがきは除く）
python3 scripts/ai_check.py <原稿フォルダ>/ep03.md # 1話だけ
```

出るもの：

1. **「〜た。」が3文続く割合**（目安 30% 以下）
2. **回数**（1万字あたり）：「――」「少しだけ」「まるで」「静かに／そっと」「黙った」。目安を超え、かつ3回以上で ⚠️
3. **型にはまった表現**：言い切り・二段ぼかし・気持ちの説明・まとめの一文・沈黙で閉じる・数え上げの台詞・決まり文句の反応（行番号つき）
4. **章末の3行**と、それが教訓・言い切り・予告・沈黙の型かどうか
5. **話をまたいだ章末の重なり**：同じ語が3話以上（全4話以下なら2話以上）の締めに出ていないか。同じ型で閉じている話

**直さずに並べるだけ。** 目印の件数は合否ではない。猫の語りの読点、落語の「――」、沈黙が主題の作品の沈黙のように、**語りの型として正しく使っているものは直さない**。
目安の数字は、点検で癖が少なかった作品の値から決めた。外れたら理由を評価ファイルに書けばよい。

話をまたいだ重なりには、主人公の名前や毎話出る場所のように「出て当然の語」も混じる。小道具として締めに使っているかどうかを、行を読んで決める。

## 評価ファイルに書くこと

```markdown
## AI臭さ（ai_check.py）

- 「〜た。」3連続：◯%（目安 30%）
- 目安超えの回数：…（なければ「なし」）
- 型にはまった表現：L◯◯「…」→ 直す／意図どおり（理由）
- 章末：「…」で閉じている → 型に当たる／当たらない
- 前の話との重なり：…（連載・連作のみ）
```

直した箇所は、ほかの指摘と同じく「修正前→修正後」の一覧に入れる。
